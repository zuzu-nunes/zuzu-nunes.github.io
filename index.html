Job Application Tracker with Read-Only Gmail Sync

Personal tool · built with an AI coding agent (Claude Code)

A job-application tracker that reads application emails from Gmail and suggests status updates (new application, rejection, interview request). It was designed around least privilege, because a tool that can read an inbox is a security risk.

  • Least privilege: the page is granted exactly one Gmail tool, search, so it cannot send, forward, change or delete email
  • OAuth-based connector: the page never sees a password or token, and access can be revoked from Google at any time
  • Prompt-injection defense: email text is passed to the AI as untrusted data, never as instructions, and output is limited to tracker fields
  • Human in the loop: every suggested change is shown with a checkbox and nothing is written until I approve it
  • Paste-to-fill: an AI reads a pasted job posting and fills in company, role, pay (hourly converted to yearly) and remote rules
  • Private cloud database with owner-only access rules, verified by testing reads at a lower permission level
